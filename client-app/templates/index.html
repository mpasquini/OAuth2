Flow overview

  1. Client generates code_verifier (random) and code_challenge = SHA-256(verifier)
  2. Browser redirects to auth server /authorize with challenge + state
  3. User logs in; auth server issues one-time code and redirects back
  4. Client POSTs code + code_verifier to /token; receives JWT
  5. Client calls resource server with Bearer <token>
